# Bank Loan Analysis Project

## Project Overview
This project analyzes bank loan application data to evaluate lending performance, borrower behavior, repayment trends, and overall portfolio health. The analysis focuses on identifying business-critical insights such as loan applications, funded amounts, repayment efficiency, good vs bad loan performance, customer segmentation, and regional distribution.

Using SQL Server, and Power BI, this project transforms raw financial data into actionable business intelligence that supports better lending strategies, risk reduction, and profitability optimization.

---

## Objectives
- Analyze total loan applications and funded capital
- Track repayment performance and revenue generation
- Measure good loan vs bad loan percentages
- Identify borrower trends by employment, home ownership, purpose, and geography
- Monitor monthly and seasonal lending patterns
- Provide business recommendations for portfolio improvement

## Key Business Insights
- Good loans dominate overall portfolio profitability
- Bad loans create measurable financial risk
- Debt consolidation is the largest loan category
- Mortgage and rent customers represent major borrower groups
- Longer employment history correlates with stronger repayment behavior
- Loan demand peaks toward year-end

---

## Top 5 Business Recommendations
1. Strengthen approval controls for high-risk borrowers
2. Expand lending for stable, high-performing customer segments
3. Optimize debt consolidation loan products
4. Improve regional and seasonal lending strategies
5. Build stronger collection and recovery systems
